# Customer support

Migration 0009 enables authenticated customer tickets, categories, threaded replies, customer-owned access, a support desk for superadmin/admin/support roles, priorities and resolution. Ten new tickets per account per 24 hours; 200 messages per thread. No email notifications, attachments, SLA promises, or agent assignment yet. The admin desk is /smartqr/support?mode=admin. All data APIs enforce permissions independent of browser mode. Test before deployment.
