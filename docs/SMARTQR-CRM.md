# SmartQR Business Admin

Private workspace at /smartqr/admin. Requires independent OIDC, migration 0007, and SMARTQR_SUPERADMIN_ID set to the immutable verified identity ID (oidc: plus 43-character hash), obtained after owner sign-in from /api/smartqr/auth/session. Never use a guessed ID or email-only superadmin bootstrap. Set provider MFA and protect environment access. Only the superadmin can grant or revoke administrative roles; other admins are bound to the verified identity ID and checked on each request. New staff must first sign in and provide their own verified identity ID. No email invitations are sent yet. No customer impersonation or payment changes.

Lead pipeline, task tracking, owner assignment, notes, estimated GBP opportunity value, real customer/trial summaries and newsletter status, audit trail. CRM data is shared internally; roles sales/support/marketing/viewer can read leads and tasks, only specified roles can edit. No team-level record security yet. Marketing status is not modified by CRM. Existing consent rules remain authoritative. Lists are capped at 500, staff at 200; pagination, campaign builder, actual billing reporting and automation rules are next steps. Audit records cover CRM writes, not all product activity. Run migration/build/unit and permission tests before deploying. No production change.
