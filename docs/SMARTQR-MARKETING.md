# Marketing contacts (beta)

Optional consent capture is separate from product use. D1 stores normalized email, original source, consent wording/version, requested/confirmed/unsubscribed timestamps and suppression status. Pending contacts are never exported as campaign recipients. Only verified operator can access summary and active CSV export. No public list endpoint.

Before public capture, complete the privacy notice and legal controller/contact, define retention/deletion policy, configure anti-bot controls and test. The current rate limiter uses hashed Cloudflare IP and email with hourly buckets; configure cleanup for expired rate-limit rows. Unverified pending records should be purged under the retention policy. No sender provider is enabled. A trusted sending worker must call prepareConfirmation, deliver confirmation and unsubscribe links to the mailbox, and process bounces/complaints. Link format: https://qr.cotiso.co.uk/smartqr/email#action=confirm&token=TOKEN and #action=unsubscribe&token=TOKEN. Never log raw tokens. Recheck active status immediately before each campaign send; CSV exports are snapshots, not evergreen mailing lists. A suppressed address cannot be reactivated by anonymous signup; a verified resubscription process is a future feature. Add provider-level one-click unsubscribe and suppression synchronization before sending campaigns. Do not send newsletters to product accounts automatically.
