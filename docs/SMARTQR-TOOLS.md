Static QR tools at /smartqr/tools: website, plain text, email, telephone, WhatsApp and vCard. PNG is rendered in the browser from SVG. No QR payloads stored by this application endpoint. Avoid sensitive content. Wi-Fi encoding has unit coverage but is deliberately not exposed via server generation; local QR rendering is a future feature. No dynamic subscription is required. Test actual scanner compatibility and deploy rate limiting before public launch.
